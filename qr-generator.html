📋 Cara Menggunakan

  1. Upload file index.html ke hosting gratis seperti GitHub Pages atau Netlify
  2. Setelah dapat URL website, masukkan di kolom atas lalu klik Generate
  3. Klik "Unduh QR Code" untuk mengunduh QR code masing-masing planet
  4. Tempelkan QR code di lembar kerja / makalah sesuai planet yang dibahas
  5. Ketika di-scan, QR code akan langsung membuka halaman planet tersebut di website
  6. Cara upload ke GitHub Pages: buat akun → buat repository baru → upload index.html → aktifkan GitHub Pages di Settings
